## New

- English product guides are included with the extension.

## Changed

- Selector words are now English only. The language setting has been removed.
- The Demo App has eight sheets with explanations and charts that respond to selections.
- Clearer field labels, separate rounded tiles and roomier variable controls make filters easier to read.

## Fixed

- A field that uses only a master dimension is listed by the master dimension's name in the property panel.
- Long dropdowns and radio lists load more values as you scroll, up to the row limit.

## Before you upgrade

- Existing objects whose look you never set by hand pick up the new defaults (rounder, more spaced tiles and larger labels), and objects set to Norsk or Deutsch now show English.
Objects made with the old Flexible Selections extension are not converted; rebuild them in this extension. Long lists load at most 2,000 rows; search finds other values.
