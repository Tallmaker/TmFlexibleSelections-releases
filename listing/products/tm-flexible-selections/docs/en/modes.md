---
title: Displays
---

Choose a display separately for each entry with **Display as**.

- **Tiles** show values as selectable tiles. Use them for a short list that can flow across, down or into a grid. Multiple values can be selected.
- **Dropdown** keeps the values in a compact control until opened. It includes search, **Select possible** and **Clear**, which helps when space is limited or the list is long.
- **List with check boxes** shows a filter-pane style list with search and a **Select all** control. Its check box shows whether none, some or all possible values are selected.
- **Button bar** joins values into a row and allows one selection at a time. It shows up to 12 values; search finds others.
- **Radio list** shows a vertical list and allows one value at a time.
- **Toggle switch (two values)** shows a single switch for a field with exactly two values, such as Yes and No. With a different number of values, it falls back to single-select tiles.
- **Date range** provides **From** and **To** inputs, quick ranges for the last 7 days, last 30 days or last 12 months, and **Clear**. The quick ranges count back from the latest date in the field. It needs date values.
- **Variable (set a value)** changes an existing app variable using buttons, a radio list, a select list or a slider. A variable calculated by a formula or a Qlik system variable cannot be changed here.
- **Bookmarks** shows bookmarks the user can access as tiles. Picking one applies its selections and variables in this app; it does not open the sheet stored in the bookmark. Choose which bookmarks to show in **Bookmarks to show**.

An entry can also list up to five other fields in **Other fields the user can switch to**. Buttons above the values let the user switch which field appears in that slot; selections and search follow the field currently shown.
