title: Overview
---

Tm Flexible Selections puts filters for many fields in one Qlik object.

Each field can use its own display, from tiles and lists to a date range, a variable control or app bookmarks. The object can also show several related fields in the same slot and use Qlik styling.

Selections apply when a user picks a value, unless the author turns on confirmation with the Qlik toolbar.
