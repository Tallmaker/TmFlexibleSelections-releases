title: Getting started
---

1. Add **Tm Flexible Selections** to a sheet in the app.
2. In **Fields**, choose **Add field**.
3. In **Field**, enter a field from the app, or choose a **Master dimension**.
4. Choose **Display as** for that field.
5. Add more fields the same way, then adjust **Presentation** or **Styling** if needed.

## Worked example

In an app with **Region** and **Category** fields, add two entries in **Fields**. Enter `Region` in the first entry's **Field** and leave **Display as** set to **Tiles**. Enter `Category` in the second entry's **Field** and set **Display as** to **Dropdown**.

The object shows a Region tile list and a Category dropdown, each with its field label. Pick **North** in Region and that selection applies at once. Open Category and pick a value such as **Bikes**; the app applies that selection too. The values come from the app's data, so the choices you see depend on the app.

See [Settings](settings.md) for the controls and [Displays](modes.md) for choosing a display.
