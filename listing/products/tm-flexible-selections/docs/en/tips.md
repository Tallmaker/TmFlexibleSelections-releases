## A long list stops loading more values

Scrolling loads up to 2,000 rows for a field. Use the search box to find values beyond that. A button bar shows up to 12 values and relies on search for the rest.

## A date looks different on another computer

Date input follows the viewer's browser format and locale. If that format does not suit the sheet, use another display such as a dropdown.

## An old Flexible Selections object is missing

Objects made with the old Flexible Selections extension are not converted. Recreate the fields and settings in Tm Flexible Selections, or use the native Qlik filter pane.

## Screen-reader behavior needs checking

Use with NVDA or VoiceOver has not been tested. Check the object with the screen reader and Qlik host used by your audience before relying on it.
